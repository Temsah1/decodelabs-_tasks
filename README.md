# 🚀 DecodeLabs — Internship Tasks (CLI Projects Collection)

This repository contains a collection of Python-based CLI applications built as part of the DecodeLabs internship program.  
Each project demonstrates core programming concepts such as file handling, control flow, data structures, and user interaction.

---

## 📦 Projects Included

### 1️⃣ Simple Expense Tracker 💰
A lightweight CLI tool to track daily expenses in real time.

**Features:**
- Real-time expense tracking
- Input validation using try/except
- Simple exit system with `quit`

---

### 2️⃣ Secure Password Generator & Validator 🔐
A cryptographically secure password generator with strength validation.

**Features:**
- Secure randomness using `random.SystemRandom`
- Customizable password length
- Option to include special characters
- Built-in password strength validator

---

### 3️⃣ CLI To-Do Manager 🚀
A terminal-based task management system with persistent storage.

**Features:**
- Full CRUD operations (Create, Read, Update, Delete)
- JSON-based persistent storage
- Priority system (High / Medium / Low)
- Smart filtering and search functionality
- Task grouping by status (Pending / Done)

---

### 4️⃣ General Knowledge Quiz App 🧠
An interactive console quiz game that tests general knowledge.

**Features:**
- Randomized questions each session
- Score tracking system
- Hint system for questions
- Replay option
- Final performance evaluation
